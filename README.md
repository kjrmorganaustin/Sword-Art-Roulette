## Project Logistics

Now heres the BORING part!

I had to set a random variable ('r') to a random number using 'Math.random()' and multiplied it by 100 (since it generates a number from 0 - 1.) I then used some simple 'if' 'then' statements to finish it all up!

First, I made it so that if r is anything less than 1, it would pop up saying "ERR. SAO Initilization Failed. Initialize project SEA TURTLE" (if you know, you know) and redirected you to r/AlicizationLyrcoris

Then, I came up with the logic for if it was more than 1.
This was quite easy, actually!
If it's more than one, complete two actions. 
1. Pop up saying "Welcome to Sword Art Online!"
2. Redirect you to r/SwordArtOnline
